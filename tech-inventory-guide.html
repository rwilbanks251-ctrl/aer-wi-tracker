Processing Inventory in Tech

Quick reference · Makor: Operations → Tech
1

PhysicalPull the device and locate the serial number on the unit itself.

2

MakorGo to Operations > Tech > Tech Summary and search by that serial (or the order number) to bring up the matching record.

3

PhysicalVisually inspect the device — screen, chassis, ports, keyboard/trackpad, missing covers or parts. Note anything unusual.

4

PhysicalConnect the device to the correct test tool (MacCheck / PhoneCheck / WipeOS) and run the standard diagnostic and wipe verification.

5

PhysicalCombine the test results with the cosmetic inspection to determine the device's actual Cosmetic Grade and Functional Grade — there is no default or shortcut grade.

6

MakorFilter the Category column to the device's category and select Filter, so like assets stay grouped as you work.

7

MakorSelect the device (or the full graded batch on the page) and choose Grade; enter the Cosmetic Grade, Functional Grade, and any Attributes (e.g. cracked screen, missing charger), then Save.

8

PhysicalPlace the device in its category's staging container/shelf, ready to move to inventory storage.

9

MakorRepeat steps 1–8 for the rest of the batch. Once every device in a category is graded and physically staged, select all and choose Move to Next Process.

10

MakorSet Next Process = Asset Inventory, Channel = Standard Resale (or the order's correct channel), then select Update.

11

PhysicalMove the device to its permanent inventory storage location, matching where Makor now shows it.

12

The section is complete once nothing is left in the Tech queue and no graded device is sitting unstaged on the floor.

Don't skip these

  • Match the physical device to its Makor tag/serial before grading — never grade from memory across a batch.
  • Flag and set aside anything that fails a physical check the system doesn't catch (loose parts, damage found after the software test passed).
  • A device isn't done until it's both graded in Makor and physically staged — one without the other is an open item.

Grade reference

CosmeticC1 – C10 scale, by wear/condition
FunctionalF1 – F6 scale, by working features

Grade every device on its actual condition — there is no default or shortcut grade for internal inventory.

Note: Container and Channel values vary by order/customer requirements — confirm the order's Instructions (top-right icon row in Makor) before moving to inventory if unsure.
