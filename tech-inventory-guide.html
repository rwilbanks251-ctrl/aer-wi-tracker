Processing Inventory in Tech

Quick reference · Makor: Operations → Tech
1

Navigate to Operations > Tech. Open Tech Summary and search for the order number.

2

Select the Category column filter funnel, type the category (e.g. Laptop), and select Filter — this groups like assets so you grade one category at a time.

3

Set items-per-page to 100 so the full filtered set fits on one page.

4

Check the header checkbox to select all assets on the page, then select Grade.

5

In the grade dialog, enter the device's actual Cosmetic Grade and Functional Grade based on real condition — testing results, screen/body wear, missing parts. Add Attributes if the device has anything callable out (e.g. cracked screen, missing charger).

6

Select Save to apply the grades to the selected assets.

7

Repeat filter → select all → grade for every remaining category. If a category has more than 100 items, work it in page sets of 100.

8

Once everything is graded, select all again and choose Move to Next Process.

9

Set Next Process = Asset Inventory, Channel = Standard Resale (or the correct channel for the order), leave Container as applicable, then select Update.

10

The section is complete once every asset on the order has been moved out of Tech and into Asset Inventory — nothing should be left sitting in the Tech queue.

Physical, at the same time

  • Pull each device from its test station/cart as it clears grading.
  • Match the physical device to its Makor tag before moving on — don't grade from memory across a batch.
  • Place graded devices in the correct staging container/shelf location for their category, ready for pickup to inventory storage.
  • Flag and set aside anything that fails a physical check the system doesn't catch (loose parts, damage found after the software test passed).

Grade reference

CosmeticC1 – C10 scale, by wear/condition
FunctionalF1 – F6 scale, by working features

Grade every device on its actual condition — there is no default or shortcut grade for internal inventory.

Note: Container and Channel values vary by order/customer requirements — confirm the order's Instructions (top-right icon row in Makor) before moving to inventory if unsure.
